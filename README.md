# ClassLibrary2

Небольшая библиотека обобщённых структур данных на C# и .NET 8. Репозиторий подходит как учебный пример реализации базовых операций над коллекциями.

## Состав

- Стек с операциями `Push`, `Pop` и `Peek`.
- Коллекция с операциями добавления, удаления и получения последнего элемента.
- Решение Visual Studio: `ClassLibrary2.sln`.

## Сборка

Установите .NET 8 SDK и выполните из корня репозитория:

```bash
dotnet build ClassLibrary2.sln
```

Проект является библиотекой и не содержит отдельного исполняемого приложения или опубликованных тестов.
